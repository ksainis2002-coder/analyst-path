The formula console

Type a formula and press Enter. The engine works it out, and the sheet lights up the cells it searched, matched and returned. Each lab below is one createConsole() call.

Lab 1 · v1 sample: orders + product table

Every formula from the v1 app, including the fixed "North + Monitor" example, plus two lookups that go wrong on purpose.

Lab 2 · a second, independent console: commission tiers

Different data, same component. Approximate match needs the first column sorted.

How a lesson embeds it

import { createConsole } from "../js/ui/console.js";
import { V1_SAMPLE } from "../js/data.js";

createConsole(document.getElementById("lab1"), {
  dataset: V1_SAMPLE,
  starter: "VLOOKUP(C2,H2:J9,2,FALSE)",
  examples: [{ formula: "SUM(F2:F25)", note: "total quantity" }],
  onResult: (result, formula) => { /* drills & grader hook in here (Phase 3–4) */ },
});
